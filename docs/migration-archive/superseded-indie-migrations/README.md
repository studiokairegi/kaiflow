# Superseded Indie Project Migrations

These seven migration files are retained for historical reference.

Their SQL is represented by newer migration files in `supabase/migrations/`
with timestamps from `20261112200258` through `20261112200336`.

The newer versions are recorded in the hosted Supabase migration ledger.
The SQL bodies were compared; the only differences were additional trailing
semicolons in the newer copies.

Do not move these archived files back into `supabase/migrations/` or apply
them again to the production database. Doing so could repeat schema changes.
